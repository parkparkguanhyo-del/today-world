# 오늘의 세계

세계지도에서 나라를 누르면 그 나라 언론의 오늘 소식을 바로 보는 뉴스 앱이에요.
돈 들이지 않고 GitHub에 올려서 인터넷 주소로 쓸 수 있어요.

## 어떻게 돌아가나요

- 1시간마다 GitHub가 `scripts/fetch-news.mjs`를 자동으로 실행해요.
- 이 스크립트가 GDELT가 15분마다 공개하는 전 세계 기사 목록 파일에서 나라별 최신 기사 **제목과 링크**를 골라 `data/news.json`에 저장해요. 기사에서 가장 많이 나온 나라를 그 기사의 나라로 정해요.
- 앱은 그 파일만 읽어요. 검색 API를 쓰지 않아서 요청 제한에 걸리지 않아요.
- 나라 사진은 한국어 위키백과에서 그 나라 도시 사진을 가져와요. 기사 사진이 아니라고 표시돼요.

## 올리는 방법 (처음 한 번만)

### 1. GitHub 가입하고 저장소 만들기
1. https://github.com 에 가입해요.
2. 오른쪽 위 `+` 버튼에서 `New repository`를 눌러요.
3. 이름에 `today-world`를 쓰고 `Public`을 고른 뒤 `Create repository`를 눌러요.

### 2. 파일 올리기
1. 새 저장소 화면에서 `uploading an existing file`을 눌러요.
2. 이 폴더 안의 파일과 폴더를 전부 끌어다 놓고 `Commit changes`를 눌러요.
3. **꼭 확인:** `.github` 폴더는 숨김 폴더라 빠지기 쉬워요. 저장소에 `.github/workflows/update-news.yml`이 안 보이면 이렇게 해요.
   - `Add file` → `Create new file`을 눌러요.
   - 이름 칸에 `.github/workflows/update-news.yml`을 그대로 써요.
   - 이 폴더의 같은 파일 내용을 복사해 붙여 넣고 저장해요.

### 3. 자동 업데이트 켜기
1. 저장소의 `Settings` → `Actions` → `General`로 가요.
2. 맨 아래 `Workflow permissions`에서 `Read and write permissions`를 고르고 `Save`를 눌러요.
3. 위쪽 `Actions` 탭 → `뉴스 자동 업데이트` → `Run workflow`를 눌러 처음 한 번 실행해요. 약 5분 걸려요.

### 4. 인터넷 주소 만들기
1. `Settings` → `Pages`로 가요.
2. `Branch`에서 `main`과 `/ (root)`를 고르고 `Save`를 눌러요.
3. 1~2분 뒤 `https://내아이디.github.io/today-world/` 주소가 생겨요.

### 5. 폰에 앱처럼 깔기
- 아이폰: 사파리로 주소를 열고 공유 버튼 → `홈 화면에 추가`
- 안드로이드: 크롬으로 주소를 열고 메뉴 → `앱 설치` 또는 `홈 화면에 추가`

## 나라 바꾸기
`countries.js`에서 나라를 더하거나 뺄 수 있어요. `fips`에는 GDELT가 쓰는 두 글자 나라 코드를 써요(예: 한국 `KS`, 영국 `UK`, 베트남 `VM`).
`x`, `y`는 `worldmap.svg` 위 위치예요. 경도와 위도로 이렇게 계산해요.
- x = ((경도 + 15) % 360) × 2.1667
- y = (75 − 위도) × 2.1667

- 기사 본문이나 언론사 사진은 넣지 마세요. 제목과 링크만 보여주고 원문으로 보내는 방식이에요.
- 위키백과 사진은 사진마다 라이선스가 있어요. 앱에 출처(위키백과) 링크를 남겨 두세요.
